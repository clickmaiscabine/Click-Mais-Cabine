# 00 — Governança

Status: homologated

Esta pasta contém os documentos que definem o que o Projeto Executivo é obrigado a respeitar.

## Arquivos

- `CLICK_MAIS_OS_BASELINE_FUNCIONAL_v1.1.md` — linha de base funcional aprovada.
- `REGISTRO_DE_DECISOES.md` — decisões humanas numeradas e rastreáveis.
- `CHANGELOG_PROJETO.md` — histórico de mudanças de escopo, arquitetura e governança.

## Regra

O Projeto Executivo pode detalhar a baseline, mas não pode modificá-la silenciosamente.

Mudança de decisão exige:
1. registro explícito;
2. motivo;
3. impacto;
4. decisão substituída, quando houver;
5. ADR quando a mudança for arquitetural.
