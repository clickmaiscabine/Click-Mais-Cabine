# Preços e regras de orçamento

Status: draft — sem valores canônicos ainda.

Preços não devem ser inferidos por LLM.

Para cada item registrar:
- ID do produto/serviço;
- nome;
- preço/base;
- vigência;
- adicionais;
- deslocamento;
- descontos autorizados;
- exceções;
- fonte/aprovação humana;
- data da última revisão.

Se o preço não estiver aprovado aqui ou em uma fonte operacional canônica futura, o chatbot deve encaminhar para orçamento, não inventar valor.
